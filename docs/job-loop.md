# 职启云帆 V1 求职闭环使用指南

V1 把“发现机会、判断投入、准备材料、跟进反馈、准备面试”放进同一条路径。系统只做整理、提醒和建议；投递、沟通和最终发送始终由用户手动确认。

## 1. 今日驾驶舱

打开首页后先看三块信息：

- **今天做什么**：逾期、今天和未来任务会进入行动队列。
- **下一场**：面试时间临近时显示面试提醒，可直接打开面试包。
- **需要继续推进**：显示在途机会和默认下一步。

任务来源于机会的 `nextAction`。完成或改期后，驾驶舱会同步更新。

## 2. 机会漏斗

进入顶部导航 **机会中心**，默认打开机会漏斗。

状态流：

```text
新发现 → 已收藏 → 定制中 → 已投递 → 沟通中 → 面试中 → Offer
                    ↓
                不适合 / 已关闭
```

- **新发现**：刚从 BOSS、手动粘贴或 CSV 进入，先判断是否值得投入。
- **已收藏**：值得继续分析。
- **定制中**：需要针对 JD 调整简历。
- **已投递 / 沟通中**：必须由用户手动确认，系统不会因为打开链接或复制 JD 自动改变状态。
- **面试中**：可打开岗位面试包。
- **不适合**：从有效漏斗退出，可撤销。
- **已关闭**：保留历史跟进，用于复盘。

每个机会都有默认下一步：

| 状态 | 默认下一步 |
| --- | --- |
| 新发现 / 已收藏 | 判断岗位是否值得投递 |
| 定制中 | 按 JD 定制简历 |
| 已投递 / 沟通中 | 跟进招聘进展 |
| 面试中 | 准备面试问题与项目案例 |
| Offer | 比较 Offer 并确认条件 |

## 3. 手动粘贴与 CSV

在机会中心展开 **手动粘贴或 CSV 预览**。

手动粘贴格式：

```text
公司 | 岗位 | 城市 | JD
```

示例：

```text
云帆科技 | AI Agent 工程师 | 上海 | 负责 Python Agent、RAG 和 FastAPI 服务开发。
```

CSV 必须包含表头：

```text
company,title,description
```

可选列：

```text
location,source,stage,nextAction,nextActionAt,channel,contact,notes,url
```

CSV 会先预览，有效行确认后写入；无效行不会被导入。相似岗位只提示重复，不会自动删除或覆盖状态。

## 4. BOSS 职位收件箱

BOSS 扩展仍只采集当前页面已显示的职位，并写入本机 SQLite 收件箱。进入 **机会中心 → BOSS 职位收件箱** 后：

- **加入机会漏斗**：把该职位保存为用户机会，后续状态由你维护。
- **用这份 JD 匹配**：把公司、岗位和 JD 带入匹配页。
- **回到 BOSS**：打开原始职位页。

加入机会漏斗不会自动投递、自动打招呼或修改 BOSS 页面。

## 5. 跟进与面试包

顶部导航 **跟进** 按时间展示逾期、今天和未来的任务。可以：

- 完成下一步
- 修改跟进时间
- 查看关联简历
- 打开面试包

面试包由规则组装，包含：

- 岗位摘要
- 匹配优势
- 能力缺口
- 技术题、项目题、行为题
- 可问面试官的问题
- 准备清单
- 当前简历来源

AI 只能作为可选增强；未配置模型或模型失败时，基础面试包仍然可用，不会编造个人经历。

## 6. 页面级数据权限

右上角“数据设置”只负责全局同步状态、API 配置和危险操作，不再提供整站导入导出。

- **简历版本页**：支持上传 PDF/TXT/DOCX 或粘贴文本，解析后先核对，再保存为简历版本；保存后可编辑、优化、匹配、下载 DOCX 或打印 PDF。
- **机会中心**：支持粘贴/CSV 预览导入，并可按当前筛选导出机会 CSV。
- **跟进页**：可按当前筛选导出投递记录 CSV。

## 7. 数据边界

- 机会、筛选视图、跟进任务和简历数据随本机 workspace 同步。
- BOSS 原始职位继续保存在本机 SQLite 收件箱。
- 手动粘贴和 CSV 机会保存在 workspace。
- API Key 仍只保存在当前浏览器。
- 系统不请求系统通知权限，不创建日历事件，不做后台提醒。

## 内置数据

`frontend/src/templateCatalog.ts` 是固定目录，包含六种原创简历版式、四类原创岗位内容框架。每种版式记录稳定 ID、版本、阅读顺序、强调色和来源。旧版应届、实习、社招 ID 保持兼容。

岗位框架包含填写提示、证据检查和面试准备问题，可选择并复制提纲；不会自动覆盖简历或为用户添加履历。范围为 Python 后端、Agent/RAG、全栈开发和数据分析。预测题明确为生成练习，不宣称真实面试题。

## 视觉方向

使用 UI/UX Pro Max 数据库检索个人作品集、天蓝配色、响应式与焦点/触控规则。根据用户明确方向选择浅天蓝背景、深海蓝文字、白纸简历和原创 SVG 地平线/纸飞机，不直接照搬数据库推荐的重动效组合。

首页标题自托管 Noto Serif SC 的小型文字子集（约 7.4 KB），完整 SIL OFL 许可证保存在 `frontend/src/assets/Noto-Serif-SC-OFL.txt`。仅首页诗意标题使用衬线字体，编辑与阅读保持系统字体；无需加载外部字体服务。颜色保留足够的文字对比，控件提供焦点状态，移动端主要触控目标至少 44px，支持减少动态效果偏好。

# Frontend Engineer JD

Company: 云帆科技

We are looking for a frontend engineer who can build polished, maintainable web experiences with React and TypeScript. The role focuses on component-driven development, responsive layouts, form-heavy product workflows, and clear UI states for loading, success, empty, and error cases.

Responsibilities:
- Build reusable React components with TypeScript.
- Develop product pages and dashboards with Vite-based frontend tooling.
- Turn user workflows into clean, accessible, and responsive interfaces.
- Work with local state, browser storage, and structured JSON data.
- Collaborate with product and design to improve usability and interaction details.

Nice to have:
- Experience with resume, recruiting, productivity, or SaaS tools.
- Understanding of frontend engineering practices such as type-safe props, data validation, and modular file organization.
- Ability to explain product decisions clearly in documentation or demos.
